# 徐州中考数学参考来源与核验记录

核验日期：2026-09-12。检索范围：2021—2026 年。用途：为原创练习提供历史卷式、知识综合方式与题目梯度参考。

**本文件不是 2027 年考试说明。用户选择的约 26 题、140 分、90 分钟是个人训练设置。2024、2025 年所读卷面写的是 28 题、140 分、120 分钟，不能把 90 分钟称为徐州官方考试时长。**

## 证据分级与“核验”的含义

- 一级来源：教育行政部门或文件原发布单位的原文。本次找到课程标准一级来源；未取得 2021—2026 各年数学真题的教育部门原始发布页。
- 二级来源：教育资料平台转载、网络资源转载或用户投稿。下文分别注明平台性质，不能写成“教育局公布”。
- 全题覆盖：实际逐页看到了第 1—28 题及相关图形，核对题号与大题结构。**不代表已独立验算每一道题，也不保证重排本没有转录错误。**
- 部分核验：只读取了部分正文或预览。只能引用看得到的栏目、页眉、题号与分值。
- 候选未核验：发现目录或题名，但未读取实际题纸；不能据此确定题型、满分、时长或命题特点。

本次仅保留链接和概要，不把历年整卷、第三方解析及原卷配图重新打包分发。原创题使用新情境、新数据、新推理组织及自行绘制的图形；不能仅把真题换数字后声称完全原创。

- “苏科版”是用户确认的个人教材版本。资料站把中考试卷自动归到“人教版”的分类标签不是教材使用证据。
- 2027 年徐州正式数学考试时长、题量、分值分配及评分细则在本次研究中未核实；不得把历史卷推断写成确定政策。

## 如何用于个人原创命题

1. 可据实际读过的 2021—2025 题目借鉴“选择—填空—解答”的顺序、由基础到综合的梯度，以及模型、图形、语言三种表示之间的转换；不能写成所有年份都固定考某一题。
2. 2021、2022、2024、2025 的大题分值可直接比较；2023 总分和前两大题来自部分原卷文本，解答总分为计算结果，应保留此区别。
3. 26 题/140 分/90 分钟由个人命题模板决定并在封面标“原创训练卷”。历史参考的 28 题/120 分钟不应原样挤入 90 分钟；应减少重复运算、控制阅读量和综合小问，按预计用时重新检查。
4. 专题卷只取相关题型、方法和由浅入深的组织方式，不能为了模仿综合中考卷而加入尚未学过的圆或其他无关章节。
5. 每道原创题必须独立求解、检查条件和图形、验算答案并设分步评分点；不能因历史来源真实便免除新题验证。
6. 如未能获取某年的正文，应继续使用已经核实的年份并说明覆盖缺口，不编造历年频率、难度系数、区分度、2027 命题趋势或学生薄弱点。

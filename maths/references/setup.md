# 安装与使用

## 在另一台 Mac 安装

1. 解压 `maths-macos-1.0.0.zip`，保持文件夹内 `maths/`、`install.py` 和 `install.command` 的相对位置。
2. 双击 `install.command`，或在终端运行 `bash "/解压目录/install.command"`。安装器优先寻找 Codex 的本机 Python，再使用可用的 `python3`；需要 Python 3.10+。也可以在目标 Mac 的 Codex 中提供解压目录并说“请运行这里的安装器安装 maths”。
3. 在 Codex 新任务中输入 `$maths`，或“帮我生成一份一元二次方程的数学试卷”。如果当前任务尚未载入新技能，在新任务中重试。

默认技能目录为 `~/.codex/skills/maths`，学生档案为 `~/.codex/maths-data`；设置过 `CODEX_HOME` 时使用对应目录。安装器在独立的 `maths-runtime` 中记录本机 Python 和数据位置，不把这台电脑的路径带到另一台。

可选安装参数：`--data-dir "/你指定的数据目录"`、`--codex-home "/你的Codex目录"`。后续重新安装会保留已有数据位置与学生档案，并备份被替换的技能代码。`MATHS_DATA_DIR` 可临时指定其他档案位置。不要把数据目录放在技能文件夹内部。

已有文档依赖时安装器直接使用；缺少时通过 pip 安装到本机 `maths-runtime/packages`，首次需要联网。可以设置 `MATHS_PYTHON` 为你的 Python 3.10+ 路径。`--skip-deps` 只供已经配置依赖的环境使用。

## Windows

代码和数据路径按 Windows 兼容方式编写。安装 Python 3.10+ 后，在 PowerShell 中运行解压目录的 `install.ps1`；也可以执行 `py -3 install.py`。Windows 实机验证状态见安装包的验证记录，不能把 Mac 测试说成 Windows 已实测。

## 平时怎样使用

- 上传错题图片，并说明“这是一元二次方程的错题，请记入错题库”。图片可以包含解题过程和对错标记。
- “我在圆这个知识点哪里容易错？帮我生成错题总结。”
- “帮我生成一份二次函数的数学试卷。”
- “帮我生成一份中考综合模拟卷。”
- “我现在圆已经学完了，请更新学习档案。”
- “请删除题号……的错题和相关记录。”

默认两种试卷都是26题左右、140分、90分钟，A4黑白打印，答案详解和分步得分点在同一个Word后面，PNG另存。错题总结不展示手写过程，但原图保存在档案。第一次没有真实错题时，只能生成基线训练，不能声称已依据个人错误完成诊断。

安装包包含已确认的初始学习设置：2027徐州中考、苏科版、130/150等；**不包含你的实际错题、作答历史或 API 密钥**。若将来给其他学生使用，应先建立对方的学生档案，避免沿用这份个人设置。当前没有多人账号管理系统。

## API 配置

在 Codex 中说“帮我配置 maths 的硅基流动 API”，或按 [API 说明](api.md) 在本机终端运行隐藏输入配置。使用自己的硅基流动密钥和账户支持的完整 DeepSeek 模型 ID。配置文件在学生数据目录，安装或转发技能不携带密钥。

只有配置密钥后的真实调用能验证账户权限和联网服务；本地 dry-run 只校验请求，不代表 API 已连通。模型返回内容仍须核算后才生成正式试卷。

## 换机带走错题

请让 Codex 按 [档案说明](archive.md) 的 backup/restore 命令迁移。备份包含数据库、原图和学生档案；生成过的 Word/PNG 成品需要另行复制，密钥在新电脑重新配置。

新安装会建立空题库。恢复时使用一个新的空目录，再将安装器 `--data-dir` 指向恢复目录（会保留其现有档案），或设置 `MATHS_DATA_DIR`。恢复后检查题数及原图。仅复制技能安装包不会自动迁移旧错题。

数据不会自动过期。删除按明确范围执行；已另存的备份和其他电脑副本需要按你的要求分别处理。

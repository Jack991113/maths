# maths

面向江苏徐州初三学生的 Codex 数学学习技能：持续积累错题，依据实际作答分析易错点，生成含数学 PNG 配图的 Word 错题总结和试卷。

## 安装

在 [Releases](https://github.com/Jack991113/maths/releases/latest) 下载 `maths-macos-1.0.0.zip`，解压并双击 `install.command`。安装器优先使用 Codex 的本机 Python；需要 Python 3.10 或更新版本，缺少文档依赖时会联网安装。

也可以下载或克隆本仓库，在仓库根目录运行：

```bash
bash install.command
```

Windows 提供 `install.ps1`，也可运行 `py -3 install.py`。目前实测平台为 macOS arm64，Windows 尚未实机验证。

安装后在 Codex 新任务中输入 `$maths`，或使用下面的自然语言指令。完整路径设置和换机步骤见 [安装与使用说明](maths/references/setup.md)。

## 使用

- 上传错题图片，并说明：“这是一元二次方程的错题，请记入错题库。”
- “我在圆这个知识点哪里容易错？帮我生成错题总结。”
- “帮我生成一份二次函数的数学试卷。”
- “帮我生成一份中考综合模拟卷。”

默认专项卷和综合卷均约 26 题、140 分、90 分钟，包含选择题、填空题和解答题；答案详解与分步得分点附在同一个 Word 后面。数学图形按明确坐标生成 PNG，嵌入文档并单独保存。

错题原图和作答事件保存至明确要求删除为止。原图中的手写过程可用于诊断，但 Word 总结不展示手写解答图片。没有真实作答证据时不编造个人错因或掌握率。

## 学习档案与 API

本仓库包含已定制的初始学习设置：2027 年徐州中考、苏科版、最近成绩 130/150，以及已确认的学习进度。给其他学生使用前，应建立对应的学生档案。当前版本不提供多人账号系统。

实际错题、原图、作答历史和 API 密钥不在仓库或安装包中。默认档案目录为 `~/.codex/maths-data`，与技能代码分开；支持自定义目录、备份和恢复，升级技能保留原有档案。仅下载技能不会迁移已有错题。

硅基流动 DeepSeek 调用为可选功能，配置方法见 [API 说明](maths/references/api.md)。使用自己的密钥和账户可用模型；接口返回内容仍须进行数学核算和文档检查。本项目已做模拟请求测试，尚未验证真实账户调用。

## 参考与验证

2021—2025 年徐州数学卷已取得全题覆盖的二级转载参考；2026 年候选题纸正文尚未核验。各年来源和核验范围见 [试卷来源记录](maths/references/exam-sources.md)。26 题、140 分、90 分钟是个人训练规格，不作为官方卷式声明。

21 项行为测试通过，覆盖档案、迁移、安装、文档和 API；原创演示卷另经数学校验及 Word 全页视觉检查。详细范围见 [验证记录](验证记录.md)。

开发时使用已有依赖的 Python，或先安装依赖，再运行测试：

```bash
python -m pip install -r maths/requirements.txt
python -m unittest discover -s tests -v
```

生成分发包：

```bash
python build_release.py
```

分发包和 SHA-256 校验文件会写入 `release/`。
